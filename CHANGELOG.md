# Changelog

## 0.2.0 — 2026-10-31

- Added English / Simplified Chinese switching with browser-persisted language preference.
- Defaulted new and upgraded sessions to English, with a small top-right EN circle that opens an accessible language menu on click. Explicit choices are remembered.
- Expanded both README languages with installation, location setup, review workflows and illustrated instructions.
- Added isolated interactive demo data and original hardware illustrations.
- Refined responsive layouts, contrast, focus handling, filter empty states and concise page headings.
- Prevented stale list requests from overwriting newer filter results.
- Made US ZIP centers and coordinates configurable, invalidating old location verification on changes.
- Added bilingual README files, screenshots, Windows CI, translation checks and browser regression checks.
- Improved installation prerequisite messages and added an allowlisted source-release packager.
- Updated Vite to 7.3.7, the patched release identified by npm audit.

## 0.1.0

Initial Windows application with Marketplace collection, hardware recognition, local valuation, price evidence, persistent review decisions, availability checks and database backups.
